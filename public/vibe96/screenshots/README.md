# Vibe96 screenshots

These dashboard capture files should be generated from the running application before Vibe96 submission. Do not fabricate screenshots or claim a feature is implemented without a real app capture.

Required files:
- admin-dashboard.png
- restaurant-dashboard.png
- charity-dashboard.png
- individual-dashboard.png
- donation-management.png
- food-listings.png

Recommended capture workflow:
1. Start the app and log in with each role.
2. Capture a 400x225 dashboard view for the admin, restaurant, charity, and individual screens.
3. Capture the donation and listing flows while the data is present.
4. Export each screenshot at 400x225 and place them in this directory.

This folder intentionally contains documentation only until a real screen capture is generated.
